# Compupler

Простой браузерный инструмент для попарного сравнения по принципу «каждый с каждым».

Приложение: [nzvyagin.github.io/compupler](https://nzvyagin.github.io/compupler/)

## Разработка

```bash
npm install
npm run dev
```

Для production-сборки используйте `npm run build`.

## Публикация на GitHub Pages

```bash
npm run deploy
```

Команда собирает приложение через Vite и при успешной сборке публикует содержимое
`dist` в ветку `gh-pages` репозитория `origin`. Флаг `--nojekyll` отключает обработку
готовой сборки Jekyll. Для публикации нужны Git и право push в `origin`.

В **Settings → Pages** репозитория выберите **Deploy from a branch**, ветку
**gh-pages** и папку **/ (root)**. При первой публикации ветка создаётся автоматически.

Для форков команда работает так же: `origin` локальной копии должен указывать на
ваш форк, а GitHub Pages нужно включить в его настройках. Сайт будет доступен по
адресу `https://<owner>.github.io/<repository>/`, где `<owner>` — владелец форка,
а `<repository>` — имя репозитория. Настройка `base: './'` в `vite.config.js`
сохраняет относительные пути к ресурсам и не требует изменения при переименовании
репозитория.
